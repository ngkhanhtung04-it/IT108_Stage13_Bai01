# GreenTech Infrastructure System

## 1.Gioi thieue thong quan ly ha tang GreenTech ho tro quan ly log may chu,

He thong quan ly ha tang GreenTech ho tro quan ly log may chu,
theo doi trang thai tram cam bien IoT va doi soat linh kien phan cung.

## 2. Cau truc du an

- `docs\`: Tai lieu ky thuat va huong dan van hanh.
- `scrpits`: Scrpits tu dong hoa.
- `data\`: du lieu log va danh muc thiet bi.
- `backup`: Bao cao su co duoc tao ra

## 3.Huong dan chay Scripts

Mo PowerShell tai thu muc goc du an va chay:

```powershell
.\scripts\auto_report.bat
```

Bao cao duoc tao tai `backup/bao-cao-su-co.txt`.

## 4.Checklist kiem tra thiet bi

- [ ] Kiem tra tram cam bien
- [ ] Kiem tra dung luong ram
- [ ] Kiem tra loai va dung luong SSD.
- [ ] Kiem tra ket noi mang.
- [ ] Kiem tra log CRITICAL, ERROR va TIMEOUT.

## 5. Bang thong so phan cung

| Thiet bi | Thong so | Muc dich                |
| -------- | -------- | ----------------------- |
| CPU      | 4 cores  | Xu ly du lieu           |
| RAM      | 8 GB     | Luu du lieu dang xu ly  |
| SSD      | 256 GB   | Luu he dieu hanh va log |
